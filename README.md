# Railroad Editor

Мобильный веб-редактор систем railroad-диаграмм. Статический сайт без backend — открой `index.html` в браузере (двойным кликом или через любой static-сервер).

## Возможности

- Создание/редактирование диаграмм: terminal, nonterminal, choice, optional, repeat, group, comment, start, end
- Sticky-стрелки: связи автоматически пересчитываются при перетаскивании узлов (anchors переназначаются по взаимному положению)
- Система связанных диаграмм: nonterminal ссылается на другую диаграмму, двойной tap открывает её, чип «‹ назад» возвращает по истории
- Проверка консистентности (кнопка ✓, автоматически после импорта): отсутствующие диаграммы для нетерминалов, дубли имён/id, отсутствие start/end, нет пути start→end, битые ссылки, недостижимые узлы, циклы между диаграммами (warning)
- Пошаговый обход (кнопка ▶): подсветка текущего/следующих узлов, вход в диаграмму нетерминала и возврат
- Импорт/экспорт: `.rrjson`, SVG, PNG, HTML с embedded SVG, standalone HTML с embedded JSON (импортируется обратно)
- Пресеты: натуральные числа, арифметическое выражение, текстовое предложение
- Undo/redo (⌘Z / ⌘⇧Z), автосохранение в localStorage, snap-to-grid, мультивыделение
- Touch: drag узлов пальцем, pan по пустому месту, pinch-zoom, long-press — контекстное меню, двойной tap — редактирование метки / открытие диаграммы

## Структура

| Файл | Слой |
| --- | --- |
| `model.js` | проект, CRUD, undo/redo, выделение, geometry (anchors, пути) |
| `traversal.js` | чистые функции обхода (getNextNodes, getReachableNodes, …) |
| `validation.js` | проверки консистентности → ValidationIssue[] |
| `presets.js` | три пресета-конструктора |
| `renderer.js` | SVG-рендер, viewport, декорации состояний, экспортный рендер |
| `interactions.js` | pointer events: tap/drag/pan/pinch/long-press/клавиатура |
| `importExport.js` | схема, нормализация, .rrjson/SVG/PNG/HTML |
| `app.js` | UI: панели, диалоги, контекстное меню, обход, `RR.api` |

Программный API (консоль браузера): `RR.api.*` — команды из ТЗ §12, `RR.traversal.*` — API обхода §5.9.
